推荐流程

  • 纯文字题目：从 Word、PDF、网页复制文字粘进输入框（PDF 建议先转成 Word 或 DOCX）。
  • 带图片的题目：直接导入 .docx 或 文字版 .pdf，工具会自动提取正文、表格和图片，并按原位置放回题干 / 选项；也可以把截图直接粘贴或拖进②校对页面的题干、选项。
  • 点「解析题目」→ 在②中核对答案、补齐图片 → 到③生成并下载独立 HTML。

图片题目（1.10 新增）

  • 导入 DOCX：Word 里的图片会按出现顺序变成 [图1]、[图2] 标记，跟在原来的题干或选项文字后面，生成页面时自动还原成图片。
  • 导入文字版 PDF：内置 PDF.js，自动提取文字和页面内嵌图片；图片按页面位置插回题目，不需要手动下载、粘贴。扫描版 PDF 没有文字层，不支持 OCR，会提示改用 Word 另存 DOCX。
  • 导入 HTML：支持带 data:image 内嵌图片的网页文件；外链图片（http/https）在离线环境无法读取，会给出提示。
  • 粘贴 / 拖拽截图：在②里点题干或选项右侧的 🖼 按钮，或直接把截图粘贴到输入框里。
  • 图片会自动压缩（最长边约 1400px）后写入题库，避免草稿超过浏览器存储上限。

支持的题目格式（混着用也行）

1. 采用集中式控制策略的网络拓扑结构是（ ）。
A. 总线型
B. 星状
C. 环状
D. 树状

2、下列属于广播信道的结构是（ ）
A、星型  B、环型  C、总线型  D、卫星

3．OSI 表示什么？(A)Operating System Information (B)Open System Interconnection (C)其它 (D)以上都对

4. 网络分层的原则包括（ ）【多选】
A. 每层功能明确
B. 层次越多越好
C. 减少跨接口通信量
D. 有助于国际化标准
答案：ACD
解析：层次过多会增加开销，B 错误。

题号 / 选项 / 答案写法

  • 题号：1. 1、 1) 1） (1) （1） 第1题。
  • 选项：A. A、 A) A） (A) （A），最多到 H；可以每行一个，也可以全挤在一行。
  • 选项内容只有一个字母也可以，例如 A.C、B.B，不会被误当成答案。
  • 答案：答案：B、1.B 2.D 3.A、1-5 BDDAC、1~10：BDDAC CBCAA，或整串纯字母 BDDAC CBCAA（按题号顺序匹配）。
  • 章节标题：一、单项选择题、二、多选题、三、判断题 会自动给后续题目设定题型。

选项字母重复 / 版面错乱时

  • 粘贴两栏 PDF 时，偶尔会在 A–D 之后又出现一组 C. / D.。工具会把重复字母的内容标为「未归属片段」，不会再塞进 D 选项，并在解析报告里原文列出，方便手动处理。
  • 如果某题选项没有分开，可在②的题目卡片里点「整理选项」，按题干里的 A. / B. 标记重新拆分（会清空本题答案，需重新选）。
  • 如果某题确认是 6 个选项（A–F），请让选项字母连续到 F；重复字母无法自动判定归属。

PDF 与扫描件

  • 文字版 PDF：直接导入即可，工具会自动提取文字、表格文字和内嵌图片，并按页面位置把图片插回题干 / 选项；几十页的 PDF 可能需要等几秒到十几秒。
  • 扫描版 / 纯图片 PDF：没有文字层，工具不做 OCR，会提示先用 OCR 工具（WPS / Adobe / 白描等）识别文字，或把截图逐题贴进选项。
  • 如果 PDF 使用了未内置的特殊字体映射，文字可能提取失败，也会提示改用 Word 转 DOCX。
  • PDF.js 已内嵌在 HTML 中（Apache-2.0），不联网、不上传文件。

🔒关于离线与隐私

  • 本工具是单个 HTML 文件，不引用任何 CDN、字体、图片或第三方脚本。
  • 断网状态下所有功能（导入、编辑、图片处理、生成、下载、预览）均可正常使用。
  • 题目、答案、图片、设置只写入浏览器 localStorage，不会发送到任何服务器。
  • 生成的检测页面同样零外部依赖，图片以 data URL 内嵌，可在 Chrome / Edge / Firefox / Safari 离线打开。
  • DOCX 解析在浏览器内完成（ZIP 解压 + OOXML 读取），PDF 解析使用内嵌的 PDF.js（Apache-2.0），都不依赖 Office 或网络。
