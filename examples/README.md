# 示例题库

这里的文件仅用于演示导入 / 生成格式，不代表项目方题库，也不包含项目方整理的教材、真题或培训机构资料。使用前请自行确认示例内容的版权。

- `示例题库-图片题.docx`：Word 图片题；题干 / 选项带图片，含表格
- `示例题库-图片题.pdf`：同一份示例内容的文字版 PDF，用于测试 PDF 自动提取
- `示例题库.txt`：纯文本示例，覆盖单选 / 多选 / 判断和常见答案写法

使用方式：

1. 打开 `dist/题目检测生成器.html`
2. ① 页面导入文件
3. 解析后到②校对
4. ③ 生成自测 HTML

如果只是想快速体验，可以在①页面点「填入示例」。
